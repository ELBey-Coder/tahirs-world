TAHIR’S WORLD WEBSITE

Includes the updated website, all six supplied artworks, and learning games.

VIEW ON WINDOWS
1. Right-click this ZIP and choose Extract All.
2. Open the extracted folder.
3. Double-click index.html to open the website in your browser.

HOSTING
Upload index.html, styles.css, script.js, and the entire assets folder to your static website hosting directory. Keep the folder structure intact. No install or build step is required.

This ZIP contains no accounts, private credentials, or hosting access settings.
